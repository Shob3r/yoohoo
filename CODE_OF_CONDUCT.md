# Elysiae Project Code of Conduct

The Elysiae project values a civil community, welcome to opinions from new and old users alike. Please read through this code of conduct to understand what we expect from the community

## 1. General Rules

We do not want to see any form of harassment of bullying on anything we control. Examples of this are:

- Trolling
- Doxxing
- Any form of Racial/Sexual/Gender-based discrimination
- Any form of harassment of members of the Elysiae project, weather it is on official channels or not

## 2. AI Policy

The Elysiae Project is **not** anti-AI, but it is also **not** pro-vibecoding. If you use AI, it must be done in a controlled manner where you still have control over most of the changes. Sometimes, the line on weather or not something is considered "vibe-coded" is sometimes thin, so here is a list of examples of what The Elysiae Project does not consider to be "vibe-coded":

1. Feature implemented with an AI agent with detailed instructions (i.e. "Add a feature that does *x* with this *y* method and *z* constraints. handle errors with *w*")
2. Using AI as a pair programmer or a debugger, given that either you implement the fix for the bug it finds, or carefully detail how you want the bug fixed
3. Resolving a merge conflict with AI, given that you are telling it exactly how to resolve the merge conflict

additionally, The Elysiae Projects expects the following rules to be taken if you do work with AI in a way that complies with the AI policy:

1. It's okay to use AI to generate comments for your work, but it shouldn't sound like an AI wrote it
2. Commit messages generated by AI are okay, but PR descriptions should be filled out by yourself. This is an additional layer of verification that helps The Elysiae Project ensure that you know what your code is doing (therefore making it less likely to be "vibe-coded")
3. Do not open issues using AI tools. You will be blacklisted from further contributions if you do so

Vibe-codied PRs will *NOT* be merged and will cause you do be blacklisted from providing additional contributions after one warning

## 3. Public Knowledge of Elysiae

Many "Anime Game" projects tend to prefer to hide in the shadows, due to their nature of being "legally gray", which could cause legal action from the games it launches on Linux. The Elysiae Project does not use any tools or libraries that could be considered cheats or exploits to get games running, and runs them completely through proton, which can be done out-of-the-box for almost all games. We also source our downloads from the main download servers, so we aren't providing any redistributions of the games in question. For these reasons, it is okay to share this project with others.
